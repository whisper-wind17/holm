# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately through **Security → Report a vulnerability** on this repository. Include the affected version (shown on the System page, or `build_version` in `release-manifest.json`), steps to reproduce and the impact you observed. Do not include real API keys, tokens or request content.

## Supported versions

Holm is in preview. Only the latest release receives fixes.

---

## 报告安全问题

安全问题请不要提交公开 Issue，请在本仓库的 **Security → Report a vulnerability** 私下报告。请写明受影响的版本（「系统」页显示的版本，或构建输出 `release-manifest.json` 中的 `build_version`）、复现步骤和观察到的影响；不要附带真实的 API 密钥、令牌或请求内容。

## 支持的版本

Holm 处于预览阶段，只有最新发布的版本会得到修复。
